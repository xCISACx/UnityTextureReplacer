Created for the Tokimeki Memorial Girl's Side for the Nintendo Switch Fan Translation Project

This script will iterate through assetbundles inside a given source folder and replace the textures inside the assetbundles with replacement textures from a replacement folder.
For the matching to work, an XML asset list must be generated through AssetStudioGUI using Export -> Asset list to XML.
The replacement folder's structure MUST match the original game's file structure, including root assetbundles which should be placed in a folder of the same name.
